# hermes-pdf-reader

Hermes 桌面应用的媒体查看器插件：**看图 + 看 PDF**，单文件，零额外运行时依赖。

## 功能

- 标题栏独立「PDF」按钮开关右侧媒体查看器，不与文件树侧边栏联动。面板通过这个按钮关闭，避免原生单插件面板的关闭动作把整个插件停用。
- 点击当前对话的图片，自动在右侧显示；`‹ ›` 或键盘 `← / →` 循环浏览当前对话已渲染的图片。不会把其他保留的 bot 对话图片混入列表。
- PDF 页支持输入任意目录、浏览 PDF、显示/隐藏目录列表；打开 PDF 后自动收起目录。
- 图片 / PDF 两个页签切换；图片下载按钮与输入框方向键保持原有行为。
- **按对话隔离**：使用连接来源、profile 和耐久会话 ID 的复合键；所属来源尚未确认时暂时收起。切到另一个 bot，不会带上前一个 bot 的文件；切回时恢复它已选择的 PDF、图片和面板开关状态。
- 起始目录取当前工作区，没有写死的课程目录或用户名。

## 安装 / 更新

1. 下载 `plugin.js`，复制到 **桌面应用实际加载的** `<hermes home>/desktop-plugins/pdf-reader/plugin.js`。文件夹名必须是 `pdf-reader`。
   Windows 的默认桌面数据根通常为 `%LOCALAPPDATA%\hermes`；使用自定义 `HERMES_HOME` 时以应用的插件目录为准。
2. 在 Hermes 桌面应用按 `Ctrl+K`，选择 **Reload desktop plugins**。不要只假定保存文件后已经热重载成功。
3. 点击右上角「PDF」按钮。无需安装 Node 依赖，也不需要重启网关。

## 验证与开发

```sh
npm install
npm test
npm run check
```

开发依赖只用于测试，不参与插件运行。回归测试运行真实插件代码和 React / DOM，SDK 与文件系统边界使用明确的测试替身。

若复用已安装的 Hermes 桌面开发依赖，可设置 `HERMES_DESKTOP_DIR` 指向含 `package.json` 的 `apps/desktop`，再运行 `npm test`。

## 已知边界

- 图片切换范围是当前对话**已渲染**的图片，不代表全部历史附件；部分图片源是对话缩略图。
- 当前查看器状态保存在这次插件运行的内存中。重载插件 / 重启应用后，需要重新选择文件。
- 恢复的是已选择的 PDF 文件。原生 PDF 查看器重新挂载时，其内部页码与缩放不保证保留。
- 需要 Hermes 桌面 SDK 的聚焦会话接口；接口缺失时提示错误，不会悄悄退回会泄露跨对话内容的全局模式。
